# 导师规定的技术范围

## 1 技术栈清单

### 1.1 后端

- Django：建议 5.2 LTS（优先）或 6.0
- Python：建议 3.12 或 3.13

### 1.2 前端

- Django Templates（随 Django 自带）
- 样式方案三选一：自定义 CSS / Tailwind CSS 4.0 / Layui 2.9.27

本项目 Windows 环境选择：**自定义 CSS + 设计 Token**（稳定、无 Node 构建依赖，视觉按规划实现简洁高级）。

### 1.3 数据库

- MySQL 8.0，库名 `flower_member`，字符集 utf8mb4

### 1.4 后台美化

- Django Admin
- django-jazzmin 3.0.1

### 1.5 图表

- ECharts 6.0
