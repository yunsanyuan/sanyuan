# 截图清单

论文 / 答辩演示建议按此顺序截图，放入 `docs/screenshots/`。仓库已按序号预置一版（嵌入式浏览器录制，宽度约 1440，登录/注册为上下分栏）。GitHub README 选用了首页、花市、会员中心、看板四张。答辩打印请在本机用 1920×1080 最大化窗口重录，避免个人桌面露出。

| 序号 | 页面 | URL 或入口 | 截图要点 |
| --- | --- | --- | --- |
| 1 | 会员登录 | `/accounts/login/` | 品牌绿、登录表单 |
| 2 | 注册 | `/accounts/register/` | 注册字段 |
| 3 | 首页 | `/` | 标语与在售花品 |
| 4 | 花市 | `/shop/` | 分类筛选、关键词搜索、价格、加购 |
| 5 | 商品详情 | `/shop/<id>/` | 库存、数量、加购 |
| 6 | 购物车 | `/orders/cart/` | 数量更新、预估折扣 |
| 7 | 结算 | `/orders/checkout/` | 储值勾选、优惠券 |
| 8 | 待支付订单 | `/orders/<id>/` | 超时说明、模拟支付成功/失败、取消 |
| 9 | 已支付订单 | 同上支付后 | 储值+网关拆分、积分 |
| 10 | 会员中心 | `/member/` | 等级、积分、储值卡片 |
| 10a | 会员资料 | `/member/profile/` | 姓名、手机、性别、生日 |
| 10b | 积分储值流水 | `/member/ledger/` | 积分账本、储值账本 |
| 11 | 领券 | `/member/coupons/` | 可领与我的券 |
| 12 | 后台登录 | `/admin/login/` | jazzmin 登录页 |
| 13 | 后台首页 | `/admin/` | 侧栏模块、品牌色 |
| 14 | 会员列表 | 后台 → 会员 | 等级、积分、储值 |
| 15 | 积分/储值流水 | 会员详情内联 | 流水记录 |
| 16 | 商品 | 后台 → 商品 | 库存、上架 |
| 17 | 订单 | 后台 → 订单 | 状态动作：支付/完成/退款 |
| 18 | 优惠券 | 后台 → 优惠券 | 剩余数量、发放 |
| 19 | 店员权限 | 店员账号登录后台 | 无用户管理、无退款动作（`19-staff-admin.png` / `19-staff-orders.png`） |
| 20 | 经营看板 | `/dashboard/` | 待支付/低库存待办、六张 ECharts 图与 KPI |

文件名：`01-login.png` … `11-coupons.png`，`12-admin-login.png` … `18-admin-coupons.png`，`19-staff-admin.png`，`19-staff-orders.png`，`20-dashboard.png`。会员资料/流水为 `10a-profile.png`、`10b-ledger.png`。
