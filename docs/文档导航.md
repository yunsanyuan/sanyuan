# 文档导航

本目录同时服务三件事：把项目讲清楚、把系统跑起来、把论文和答辩写完。  
根目录 [README.md](../README.md) 是 GitHub 首页；你现在读的是文档索引。  
学术禁止事项见 [../NOTICE.md](../NOTICE.md)：本成果尚未答辩，不得作为他人毕业论文提交。
