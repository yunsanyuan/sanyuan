# 花店会员管理系统 · 前期规划

> 立项时的范围稿。已实现功能以 [功能清单.md](功能清单.md) 为准；对外介绍看 [项目概述.md](项目概述.md)。

本科毕业设计。单体 Django（MVT）服务端渲染 + Django Admin。

- 后端：Python 3.13 · Django 5.2 LTS · Django ORM
- 前端：Django Templates · 自定义 CSS（品牌色规范）· ECharts 6.0
- 后台：Django Admin · django-jazzmin 3.0.1
- 数据库：MySQL 8.0 / `flower_member`

范围内：会员、商品、订单、积分、等级、储值、优惠券、角色权限、数据看板。  
范围外：真实支付网关、物流售后、多门店。

核心闭环：下单 → 模拟支付 → 扣库存 → 储值抵扣/核销券 → 累计积分 → 等级升降 → 流水 → 看板。
