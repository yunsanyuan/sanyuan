# 业务规则（默认值）

演示系统，不接真实支付。金额单位：人民币元，精度两位小数。

## 角色

- 管理员：全量后台管理与看板
- 店员：商品、订单、会员查询、收银相关
- 会员：前台注册登录、资料自改、会员中心、积分/储值流水、自助下单

管理员/店员走 Django Admin；会员走前端页面。统一账号模型 `accounts.User`，字段 `role` 区分。

## 后台权限（RBAC）

- 管理员：`role=admin`，同步为超级用户，可管理账号、等级、优惠券、退款与全部数据。
- 店员：`role=staff`，可登录后台；商品上下架与库存、购物车/收银支付/完成订单、会员只读查询、发放优惠券、审核会员取消申请；不可管用户、不可改等级规则、不可创建券模板、不可对已发货/已签收单直接退款。
- 会员：不能登录 `/admin/`。

## 积分

- 已支付订单按实付金额累计，1 元 = 1 积分（向下取整）
- 「累计积分」是净值：退款按该单已发积分同时扣回当前积分与累计积分，不为负，并按净值重新套档（可能降级）
- 记录 `member_points_record` 流水（来源、变动、余额快照、关联订单）

## 等级

| 等级 | 升级所需累计积分 | 折扣 | 积分倍率 |
| --- | --- | --- | --- |
| 普通 | 0 | 100% | 1.0 |
| 银卡 | 1000 | 98% | 1.1 |
| 金卡 | 5000 | 95% | 1.2 |
| 钻石 | 10000 | 92% | 1.5 |

支付成功后按累计积分自动升降。折扣作用于商品合计，再叠加优惠券；券后金额为实付基数。

## 储值

- 每会员一个储值账户，余额 >= 0
- 充值增加余额；支付可选储值抵扣；退款回补已抵扣金额
- 记录 `member_store_record`（充值/消费/退款）
- 会员可自助充值（模拟网关，单笔 1–2000 元，档位 50/100/200/500/1000/2000）。失败不关单，成功才入账，不赠积分。待入账 30 分钟超时关闭。每人同时只能有一张待入账。
- 管理员仍可在后台给会员调账充值。店员不能充值，也看不见充值单。

## 优惠券

- 类型：满减、折扣。门槛按商品合计判断；抵扣发生在等级折扣之后，应付不为负。
- 券模板总量表示可发放名额；已领取、已核销占名额，过期后释放，可再领。
- 状态：未领取 / 已领取 / 已核销 / 已过期。
- 下单时自动选用最优可用券并核销；取消待支付订单退回优惠券；支付成功后退款不退券。
- 一单一张券。可用 `python manage.py expire_coupons` 或后台动作扫描过期。

## 订单状态

待支付 → 已支付 → 配送中 → 已签收  
待支付 → 已支付 → 已签收（自提，店员核销）  
待支付 → 已取消  
已支付 → 待退款审核 → 已退款（店员/管理员同意）  
待退款审核 → 已支付（驳回或会员撤回）  
已支付 / 待退款审核 / 配送中 / 已签收 → 已退款（仅管理员可对未申请单直接退）  

配送单结算时写收花人/电话/地址快照，已支付后不能改地址。未发货（或自提未核销）会员只能**申请取消**，不能直接退款：库存继续预扣，防止占库存后立刻退款。店员或管理员同意后整单退款（回库存、回储值、扣积分，券不退）；驳回后继续备花/自提。审核中不能发货或核销。已发货后会员不能申请，管理员仍可退款（不模拟退货物流）。会员可确认签收；不能自己点「我已自提」。后台从购物车下单默认自提。

状态变更写记录。待支付订单 **30 分钟** 未支付即自动取消：回补库存、退回优惠券。扫描发生在进入首页、花市列表/详情、订单列表/详情、结算、支付、会员中心和经营看板时，也可用 `python manage.py expire_pending_orders`。不使用 Celery。会员仍可手动取消。

## 库存与订单

- 加购与改购物车数量不超过当前库存；下单成功再预扣。取消待支付或退款时回补。后台待支付单一旦已预扣，明细只读（与已支付相同），不能改数量或增删行；未预扣的草稿可补行，保存时再预扣。
- 支付：应付 = 商品合计 − 等级折扣 − 优惠券。可优先扣储值，剩余走模拟网关。
- 模拟支付失败不改状态、不入账；成功后记支付流水、发放积分、升降级。
- 积分 = ⌊实付金额 × 当前等级积分倍率⌋。

## UI

前台森绿：主色 `#355E4B`，加深 `#2A4A3C`，浅底 `#E7EEEA`，页面底 `#F3F1ED`，卡片 `#FFFFFF`，正文 `#2C2B28`，次级 `#6F6C67`，边框 `#E3DFD6`。口号：以花为集，以客为心。后台桌面端为主，会员端兼顾移动端。经营看板使用 ECharts 6.0：销售趋势、订单状态、会员增长、等级分布、畅销商品、积分/储值/优惠券；入口 `/dashboard/`，管理员与店员可看。看板顶部为店务待办：待支付订单、待履约（待发货/待自提）、待审核取消、库存 ≤ 8 的在售花品。实收统计含已支付、待退款审核、配送中、已签收（审核通过前仍算实收）。
