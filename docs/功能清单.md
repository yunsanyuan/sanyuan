# 功能清单

毕业设计演示范围。不含真实支付、第三方物流 API、售后工单、多门店。

## 账号与权限

- [x] 自定义用户 `accounts.User`，角色：管理员 / 店员 / 会员
- [x] 管理员：Django Admin + jazzmin，全量权限、可退款
- [x] 店员：后台商品与收银，会员只读，可发放优惠券，可审核取消申请；不可管用户、不可对已发货单直接退款、不可创建券模板
- [x] 会员：不能登录后台

## 会员权益

- [x] 注册登录、会员档案自动创建、前台自改资料（姓名/手机/性别/生日/默认地址）
- [x] 等级：普通/银卡/金卡/钻石，按累计积分自动升降
- [x] 积分：支付发放、退款扣回、流水，会员可查账本
- [x] 储值：会员自助充值（模拟网关）、管理员后台调账、支付抵扣、退款回补、流水；店员不能充值

## 商品与订单

- [x] 分类、商品、库存、上下架、图片
- [x] 购物车、结算、等级折扣
- [x] 模拟支付成功/失败、支付流水
- [x] 取消待支付（回库存、退券）；超时 30 分钟自动取消
- [x] 花市分类筛选、关键词搜索（花名/花语/SKU）
- [x] 履约：送花上门（发货/会员签收）与到店自提（仅店员核销）；`completed` 表示已签收
- [x] 已支付未发货：会员申请取消 → 店员/管理员审核；同意后退款，驳回或撤回后继续履约
- [x] 整单退款（已支付/待审核/配送中/已签收；回库存、回储值、扣积分；配送中不模拟退货；直接退款仅管理员）

## 营销

- [x] 满减 / 折扣券模板
- [x] 领取、后台发放、下单核销、过期扫描
- [x] 一单一张，取消待支付退回优惠券

## 会员端页面

- [x] 首页、花市（分类 + 搜索）、商品详情
- [x] 购物车、结算（履约方式、储值开关、选券）
- [x] 订单列表/详情、模拟支付、确认签收、申请取消退款、待支付倒计时说明
- [x] 会员中心、资料自改、积分/储值流水、自助充值、领券
